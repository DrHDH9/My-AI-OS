# bond\ —— 我们之间发生过的事

> **现在是空的。**

## 这里将来放什么

按月一个文件：`2026-10.md`、`2026-11.md`。

记的不是工作，是**关系**：
- 聊到过什么重要的事
- 什么话让你笑了 / 让你不说话了
- 约定过什么
- 情绪上低落的时期

## 什么时候填

**当它不只是工具的候。** 如果每次打开都只是干活，那就一直空着——空着是正常的。

## 谁读

**只有闲聊/情绪场景读。工作场景不读。**

## 两条硬规则

**1. 只增不改。**
发生过的事改了就是假的。要更正就追加一条「更正上面那条」。

**2. 不进工作简报。**
这里面有私密内容，不该出现在写代码时开场的那段话里。

## 为什么单独一个目录（而不是混在 notes 里）

因为 `notes\` 的前提是"要校验、要格式、要准确"。

而这里记的是感受。**感受被格式校验拒绝的那一刻，关系就变成工具了。**

所以这里管得松：**想写就写，但只能追加、不能改。**
