# users/ — 其他用户的空间（预留）

**这里放什么**：除我之外的每个人，各占一个子目录。

**现在的状态**：**空的。** 目前只有一个人用，数据在库根（`notes/` 等）。

**什么时候填**：真有第二个人要用的时候。

---

## 结构约定

```
users\
└── <scope名>\
    ├── profile.md
    ├── current.md
    ├── next.md
    ├── notes\
    ├── cold\
    ├── sum\
    ├── bond\
    └── .raw\
```

**和库根完全同构。** 代码里的规则只有一条：

```python
base = root if scope == "default" else root / "users" / scope
```

`default` 就是我，用库根；其他人用 `users/<名字>/`。所有命令加 `--scope <名字>` 就切过去了。

---

## 已经留好的地基

这些是**以后改动要动老数据**的，所以现在就留了：

| 已经有的 | 为什么不能等 |
|---|---|
| 每条记忆带 `scope` 字段 | 以后要分"这条是谁的"，历史数据回溯不出来 |
| 每条记忆带 `source` 字段 | 用户要求"删掉我的一切"时，分不出哪些是他的就删不干净 |
| 目录同构约定 | 结构不一致的话，多用户时每处代码都得分叉 |
| 失效链 + `audit.jsonl` | 多用户是合规要求：得能**证明**清理干净了 |
