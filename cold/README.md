# cold/ — 冷存层

**这里放什么**：活跃层（`notes/`）超过上限后，被 `mem.py tier` 移过来的旧记忆。

**什么时候填**：`mem.py tier` 自动移，一般不用手动碰。活跃层数超过 `config.json` 里 `capacity.active_limit` 时才会发生。

**谁读**：
- `search` **会搜这里**（结果标注「冷存」）
- `brief` **不读这里**（只有活跃层进简报）

---

## 三条规矩

1. **移过来不等于删除。** 冷存里的东西一样能搜到、能 `why`、能被 `--supersede` 取代。
2. **不要手动往这里放文件。** 想让它不进简报，正确做法是让它失效（`--supersede`），不是搬到这里。
3. **想捞回活跃层**：直接把文件 `move` 回 `notes/` 就行，然后跑 `mem.py rebuild`。搬家不是删除，随时可逆。
